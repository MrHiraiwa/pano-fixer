# 🌐 pano-fixer ✨

> AI編集や画像加工で消えてしまった360度パノラマ画像のメタデータ復元・完全移植、およびGoogle Maps / ストリートビュー向けの方角（Heading）＆撮影位置（GPS）調整ができるWebツールです。

🔗 **Live Demo:** [https://mrhiraiwa.github.io/pano-fixer/](https://mrhiraiwa.github.io/pano-fixer/)

---

## 📌 概要

AIによる画像編集ツール（画像生成AI、不要物削除、高画質化など）を通すと、画像内に含まれる360度パノラマ用のメタデータ（Google Photo Sphere / GPano XMP や Exif情報）が消失し、VRビューアやSNS、マップ上で平面画像として認識されてしまう問題が発生します。

**pano-fixer** は、ブラウザ上で画像バイナリを直接解析・再構成し、360度画像として再認識させるためのタグ復元や、正面の方位角（向き）・撮影位置（GPS）の調整を行います。

---

## 🚀 主な機能・特徴

* **🔄 3つの専用モード**
  * **🧭 方角・位置だけ調整:** 手元にある360度写真の正面向きや撮影ピン位置だけをサクッと調整（画像1枚でOK）。
  * **🔄 元画像からタグ移植:** 撮影直後の元ファイルからカメラ固有情報（Exif / GPano / GPS等）を丸ごと抽出し、編集後画像へ完全クローン。
  * **⚙️ 新規360°タグ生成:** 元画像が手元にない場合でも、Google Photo Sphere（GPano）準拠の標準XMPメタデータとExifをゼロから注入。
* **🧭 パノラマプレビュー連動の方角（Heading）調整**
  * パノラマ画像を左右にドラッグするだけで、コンパス目盛り（北・東・南・西）と連動して「正面（Google Mapsの初期表示アングル）」を直感的に設定可能。
* **📍 地図クリックで直感GPS位置情報埋め込み**
  * 内蔵マップ（OpenStreetMap）をクリックするだけで撮影地点にピンを立て、緯度・経度メタデータを画像に埋め込み。
  * 元画像にGPSが含まれる場合はExifバイナリから座標を自動抽出し、撮影場所へマップが自動ジャンプします。
* **🎨 PNG形式の自動変換対応**
  * AIツール等から出力されたPNG画像も、ドラッグ＆ドロップするだけで最高品質（ロスレス相当）のJPEGへ自動変換して処理。
* **🔒 100% クライアントサイド処理（完全プライベート）**
  * すべての処理はブラウザ内のJavaScriptで行われます。画像が外部サーバーに送信されることは一切ありません。

---

## 📷 対応カメラ・フォーマット

* **入力フォーマット:** JPEG / JPG / PNG（正距円筒図法 / Equirectangular 形式）
* **出力フォーマット:** メタデータ付き JPEG
* **対応カメラ:** Insta360 シリーズ、RICOH THETA、GoPro MAX、DJI、その他各種360度カメラ・CGレンダリング画像

---

## 🛠 使い方

1. [Webアプリ（GitHub Pages）](https://mrhiraiwa.github.io/pano-fixer/) にアクセスします。
2. 目的に応じてモードを選択します。
3. 画像をドラッグ＆ドロップでセットします。
4. プレビューをドラッグして **正面の方角** を合わせ、必要に応じて **地図上で撮影場所（GPS）** をクリックします。
5. **「メタデータを更新して保存」** ボタンをクリックすると、修復済みのパノラマ画像がダウンロードされます。
