# 🌐 pano-fixer ✨

> AI編集や画像加工で消えてしまった360度パノラマ画像のメタデータを、ブラウザ上で簡単に復元・完全移植するWebツールです。

🔗 **Live Demo:** [https://mrhiraiwa.github.io/pano-fixer/](https://mrhiraiwa.github.io/pano-fixer/)

---

## 📌 概要

AIによる画像編集ツール（画像生成AI、不要物削除、高画質化など）を通すと、画像内に含まれる360度パノラマ用のメタデータ（Google Photo Sphere / GPano XMP や Exif情報）が消失し、VRビューアやSNSで平面画像として認識されてしまう問題が発生します。

**pano-fixer** は、ブラウザ上でJPEGバイナリを直接解析・再構成し、360度画像として再認識させるためのタグを復元・付与します。

---

## 🚀 特徴

* **🔄 2つの復元モード**
  * **元ファイルから移植（クローン）**: 撮影直後のオリジナル画像からメタデータセグメント（Exif / XMP / MakerNote等）を丸ごと抽出し、編集後画像へ完全に移植します。
  * **新規360°タグ生成**: 元画像が手元にない場合でも、画像解像度に合わせてGoogle Photo Sphere（GPano）準拠の標準XMPメタデータを直接生成・注入します。
* **🔒 100% クライアントサイド処理（完全プライベート）**
  * すべての処理はブラウザ内のJavaScriptで行われます。画像が外部サーバーにアップロードされることは一切ありません。
* **✨ 画質の完全維持（ロスレス）**
  * 画像のピクセルデータを再エンコードしないため、圧縮による画質の劣化がありません。
* **📦 ゼロ依存（No Dependencies）**
  * 外部ライブラリを一切使用していないため、軽量かつオフラインでも動作します。

---

## 📷 対応カメラ・フォーマット

* **対応フォーマット:** JPEG / JPG（正距円筒図法 / Equirectangular 形式）
* **対応カメラ:** Insta360 シリーズ、RICOH THETA、GoPro MAX、DJI、その他各種360度カメラ・CGレンダリング画像

---

## 🛠 使い方

1. [Webアプリ（GitHub Pages）](https://mrhiraiwa.github.io/pano-fixer/) にアクセスします。
2. 目的に応じてモードを選択します。
   * **元ファイルから移植:** 「AI編集後の画像」と「撮影元のオリジナル画像」の2枚をセット
   * **360°タグを新規生成:** 「編集後の画像」のみをセット
3. **「メタデータを付与して保存」** ボタンをクリックすると、修復済みの画像がダウンロードされます。
