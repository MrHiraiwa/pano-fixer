# 🌐 pano-fixer ✨

> AI編集や画像加工で消えてしまった360度パノラマ画像のメタデータ復元・完全移植、およびGoogle Maps / ストリートビュー向けの方角（Heading）調整ができるWebツールです。

🔗 **Live Demo:** [https://mrhiraiwa.github.io/pano-fixer/](https://mrhiraiwa.github.io/pano-fixer/)

---

## 📌 概要

AIによる画像編集ツール（画像生成AI、不要物削除、高画質化など）を通すと、画像内に含まれる360度パノラマ用のメタデータ（Google Photo Sphere / GPano XMP や Exif情報）が消失し、VRビューアやSNS、マップ上で平面画像として認識されてしまう問題が発生します。

**pano-fixer** は、ブラウザ上で画像バイナリを直接解析・再構成し、360度画像として再認識させるためのタグ復元や、正面の方位角（向き）の調整を行います。

---

## 🚀 特徴

* **🔄 2つの復元モード**
  * **元ファイルから移植（クローン）**: 撮影直後のオリジナル画像からメタデータセグメント（Exif / XMP / MakerNote等）を丸ごと抽出し、編集後画像へ完全に移植します。
  * **新規360°タグ生成**: 元画像が手元にない場合でも、画像解像度に合わせてGoogle Photo Sphere（GPano）準拠の標準XMPメタデータを直接生成・注入します。
* **🧭 Google Maps / ストリートビューの方角調整**
  * 画像中央が向いている方位角（`GPano:PoseHeadingDegrees`）をスライダーやプリセット（北・東・南・西）で指定可能。元画像がある場合は既存の方位を自動読み込みします。
* **🎨 PNG形式の自動変換対応**
  * AIツール等から出力されたPNG画像も、ドラッグ＆ドロップするだけで最高品質（ロスレス相当）のJPEGへ自動変換して処理します。
* **🔒 100% クライアントサイド処理（完全プライベート）**
  * すべての処理はブラウザ内のJavaScriptで行われます。画像が外部サーバーに送信されることは一切ありません。
* **📦 ゼロ依存（No Dependencies）**
  * 外部ライブラリを一切使用していないため、軽量かつオフラインでも動作します。

---

## 📷 対応カメラ・フォーマット

* **入力フォーマット:** JPEG / JPG / PNG（正距円筒図法 / Equirectangular 形式）
* **出力フォーマット:** メタデータ付き JPEG
* **対応カメラ:** Insta360 シリーズ、RICOH THETA、GoPro MAX、DJI、その他各種360度カメラ・CGレンダリング画像

---

## 🛠 使い方

1. [Webアプリ（GitHub Pages）](https://mrhiraiwa.github.io/pano-fixer/) にアクセスします。
2. 目的に応じてモードを選択します。
   * **元ファイルから移植:** 「編集後の画像」と「加工前の元画像」の2枚をセット
   * **360°タグを新規生成:** 「編集後の画像」のみをセット
3. 必要に応じて **方角（Heading）** を調整します。
4. **「メタデータを付与・調整して保存」** ボタンをクリックすると、修復済みの画像がダウンロードされます。
